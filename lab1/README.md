# МАС · лабораторная работа №1

**Тема:** спецификация и архитектурное проектирование многоагентной системы распределения заказов между курьерами.

**Выполнил:** Мозговой Кирилл Сергеевич, группа Б24-517.

## Состав

- `report.pdf` — самостоятельный отчёт без исходного кода и демонстрационных трасс.
- `report.md` — редактируемый текст отчёта.
- `src/simulation.py` — исполняемый прототип, только стандартная библиотека Python.
- `demo/index.html` — автономный просмотр трёх сохранённых запусков; открывается двойным щелчком, интернет не нужен. Это просмотр трасс, а не запуск Python в браузере.
- `demo/*.json` — полные журналы сообщений и результаты.
- `tests/test_simulation.py` — пять проверок протокола и ограничений.
- `build_materials.py` — воспроизводимая сборка отчёта и демонстрации; для неё требуется `reportlab` и шрифты DejaVu Sans. Для самой симуляции эти зависимости не нужны.

## Запуск

Нужен Python 3.10 или новее. Выполнять команды из папки `lab1` (после клонирования репозитория выполните `cd lab1`):

```sh
python src/simulation.py --scenario normal --output demo/normal.json
python src/simulation.py --scenario overload --output demo/overload.json
python src/simulation.py --scenario capacity --output demo/capacity.json
python -m unittest discover -s tests -v
```

В Linux вместо `python` может потребоваться `python3`.

Политика по умолчанию — `nearest`: минимальная оценка времени маршрута среди свободных курьеров с подходящей грузоподъёмностью. Дополнительный переключатель `--policy round_robin` включает циклическое назначение. Он предусмотрен для продолжения работы; полноценное сравнительное исследование механизмов относится к ЛР2 и в этот отчёт не входит.

Все запуски детерминированы. `--horizon 120` задаёт предел моделирования. При наличии невыполнимого заказа симуляция доходит до предела и сохраняет его как `waiting`.

## Условности модели

Дискретное время, манхэттенское расстояние, один заказ на курьера, движение сначала по x, затем по y. Нулевая длительность погрузки и выгрузки; события движения фиксируются в конце такта. Надёжная FIFO-шина в одном процессе, без сетевых задержек и потерь. Сообщения `STATUS` посылаются в конце каждого такта активного курьера. Дедлайн — желательное время доставки, опоздание не отменяет заказ.
