## Исследование механизмов распределения задач и координации

Продолжение модели доставки из ЛР1. Сравниваются три механизма:

- `round_robin` - централизованное циклическое назначение свободным подходящим курьерам.
- `nearest` - диспетчер выбирает минимальную оценку времени маршрута.
- `contract_net` - запрос предложений всем курьерам, локальные заявки, выбор победителя и назначение.

В модель входят источник заказов, диспетчер и 3 либо 6 курьеров. Логика каждого механизма явно реализована на Python. Контрактная сеть использует синхронные раунды без задержки связи; это упрощённый протокол, а не полная реализация стандарта FIPA.

## Запуск

Для симуляции, экспериментов и тестов нужен Python 3.10+; используются только стандартные библиотеки. Из корня репозитория:

```sh
cd lab2
python run_experiments.py
python -m unittest discover -s tests -v
```

Для отдельного полного журнала:

```sh
python src/simulation.py --scenario normal --policy contract_net --output results/example.json
```

Доступны сценарии `normal`, `overload`, `capacity` и три политики из списка выше. Экспериментальные сценарии `sparse`, `stream`, `burst` создаются в `run_experiments.py`. Девять полных экспериментальных трасс записываются в `demo/traces.json` при воспроизведении; из-за большого объёма файл не включён в репозиторий. Данные всех 360 прогонов и входные наборы включены.

Для сборки PDF и обновления HTML:

```sh
python -m pip install reportlab
python build_materials.py
```

Нужны DejaVu Sans по пути `/usr/share/fonts/truetype/dejavu`; путь задаётся в `build_materials.py`. Для просмотра готовой демонстрации скачайте репозиторий, распакуйте и откройте `lab2/demo/index.html` в браузере. Сервер и интернет не требуются. HTML показывает первые 120 сообщений каждого из девяти демонстрационных запусков и их итоговые метрики; полный журнал доступен после воспроизведения.

## Методика

60 заказов, 3 режима поступления, 2 размера парка, 20 начальных значений генератора. Каждый набор используется всеми тремя механизмами. Метрики: общее время выполнения, среднее и p95 времени заказа, опоздания, путь, число сообщений, объём координационных сообщений в UTF-8 и вариация числа назначений между курьерами.

Связь мгновенная и надёжная. Контрактная сеть заново запрашивает предложения для каждого ожидающего заказа на каждом такте, включая отказы занятых курьеров. Такая политика повторов создаёт значительные расходы при перегрузке. Время CPU, задержки сети и пропускная способность каналов не моделируются; объём JSON - оценка трафика, не цена в рублях.
